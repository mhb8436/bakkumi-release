# bakkumi

- 소개·다운로드·지원·개인정보 처리방침: **https://mhb8436.github.io/bakkumi-release/**
- 최신 DMG 바로 받기: https://github.com/mhb8436/bakkumi-release/releases/latest/download/bakkumi.dmg
- Homebrew: `brew install --cask mhb8436/bakkumi/bakkumi`
